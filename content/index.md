# Obsidian 知识库

这是本群共同维护的长期知识库，用于沉淀学习笔记、习题整理、资料说明，目前正在持续更新。后续会接入Astrbot机器人，作为机器人知识库的一部分。

网站基于 Obsidian 与 Quartz 构建，支持搜索、标签、知识图谱、评论、GitHub 登录、已读标记和收藏标记。

**更新:** 通过接入文本嵌入模型与对话模型，实现了**AI辅助查找笔记功能(需要github登录后才能使用)**

项目 GitHub 仓库：[blueraina/group-vault](https://github.com/blueraina/group-vault)

## 如何使用

你可以通过左侧目录、搜索框、标签页和知识图谱浏览内容。

登录 GitHub 后，可以发表评论，并使用已读、收藏等个人标记功能。已读和收藏记录会与登录账号绑定。

如果全局图谱中的题目节点过多，可以在图谱设置中隐藏特定标签。

## 协作方式

有仓库权限的维护者可以在 Obsidian 中修改笔记，并通过 Obsidian Git 同步到 GitHub。

如果你想分享自己的数学笔记，展示在网站上，欢迎联系我！
