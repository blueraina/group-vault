# 入门指南

这个知识库用于沉淀本群长期有价值的信息，包括教程、经验、规则、常见问题和已经整理过的资料。

## 如何阅读

- 从 [[00-首页]] 开始浏览。
- 通过页面里的双链跳转到相关主题。
- 在网页版本中可以使用搜索和图谱功能。

## 如何贡献

有 GitHub 权限的群友可以新建分支，修改后通过 Pull Request 提交审核。不熟悉 Git 的群友可以通过 Issue 投稿，由管理员整理。

贡献前请阅读仓库根目录的 `CONTRIBUTING.md`。

## 如何查看网页版本

网页版本会由 Cloudflare Pages 自动发布。部署完成后，访问地址会写在 `README.md` 中。

## 注意事项

- 不要直接修改 `main` 分支。
- 不要提交敏感信息。
- 不要上传未授权转载内容。
- 图片请放在 `assets/images/`。
