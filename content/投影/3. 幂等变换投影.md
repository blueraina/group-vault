这篇笔记中，我们介绍另一种极为常见的投影: **幂等变换投影**

> [! ] 幂等变换定义
> 设 $V$ 是一个线性空间，$P$ 是 $V$ 上的一个线性变换。如果 $P$ 满足：
$$P^2 = P$$
那么 $P$ 就被称为**幂等变换**，同时也称 $P$ 是 $V$ 上的一个**投影变换**

对于任意向量 $x \in V$，我们可以写成
$$x = Px + (I - P)x$$
第一部分 $Px$：显然属于 $P$ 的像空间 $\mathrm{Im}P$
第二部分 $(I - P)x$：如果我们对它再施加一次 $P$，会得到 $P(x - Px) = Px - P^2x$。因为 $P^2 = P$，所以 $Px - Px = \mathbf{0}$。这意味着 $(I - P)x$ 属于 $P$ 的核空间 $\mathrm{Ker}P$。
因此任何一个幂等变换 $P$，都唯一对应着一个空间的直和分解：
$$V = \mathrm{Im}P \oplus \mathrm{Ker}P$$
变换 $P$ 的作用，就是把任意向量 $x$ 沿着平行于 $\mathrm{Ker}P$ 的方向，投影到 $\mathrm{Im}P$ 上(从 $x$ 到 $Px$ 的“连线向量”（也就是 $x - Px$）都属于 $\mathrm{Ker}P$)

---

下面看几个例子

> [!example] 幂等变换投影
>  设 $\sigma$ 为 $n$ 维欧氏空间 $V$ 上的投影变换, 即 $\sigma^2=\sigma$. 证明: 若 $\forall\alpha\in V$, 都有 $|\sigma(\alpha)|\le|\alpha|$, 则 $\ker\sigma\perp\text{Im }\sigma$.

**方法 1:**  用反证法. 假设 $\ker\sigma\perp\text{Im }\sigma$ 不成立, 则存在 $\alpha\in\text{Im }\sigma$ 及 $\beta\in\ker\sigma$, 使得 $(\alpha,\beta)\neq 0$. 作与 $\beta$ 正交的向量 $\xi=\alpha-\frac{(\alpha,\beta)}{(\beta,\beta)}\beta$, 易知
$$ (\xi,\xi) = (\alpha,\alpha) - \frac{(\alpha,\beta)^2}{(\beta,\beta)} < (\alpha,\alpha). $$
此外, 设 $\eta\in V$ 使得 $\sigma(\eta)=\alpha$, 利用 $\sigma^2=\sigma$, 可知 $\sigma(\alpha)=\alpha$. 又 $\sigma(\beta)=0$, 所以 $\sigma(\xi)=\alpha$,
从而 $(\sigma(\xi),\sigma(\xi)) > (\xi,\xi)$. 此与题设矛盾. 因此 $\ker\sigma\perp\text{Im }\sigma$.

**方法 2:** 任取 $\alpha\in\ker\sigma$ 及 $\beta\in\text{Im }\sigma$, 则 $\sigma(\alpha)=0$, 且存在 $\gamma\in V$ 使得 $\beta=\sigma(\gamma)$. 对任意实数 $x\in R$, 令 $\xi=\alpha+x\beta$, 则由 $\sigma^2=\sigma$ 得 $\sigma(\xi)=\sigma(\alpha+x\beta)=x\sigma(\gamma)=x\beta$. 对 $\xi$ 利用题设条件, 有
$$ x^2|\beta|^2 \le|\alpha+x\beta|^2=|\alpha|^2+x^2|\beta|^2+2x(\alpha,\beta), $$
所以 $|\alpha|^2+2x(\alpha,\beta)\ge 0$. 注意到 $x\in R$ 的任意性, 于是有 $(\alpha,\beta)=0$. 因此 $\ker\sigma\perp\text{Im }\sigma$.

**注:** 本题具有明显的几何意义: 首先由 $\sigma^2=\sigma$, 知 $V=\text{Im }\sigma\oplus\ker\sigma$ , 且 $\sigma$ 是由 $V$ 到 $\text{Im }\sigma$ 的投影变换. 注意到 $\forall\alpha\in V$, 都有 $|\sigma(\alpha)|\le|\alpha|$, 即像 $\sigma(\alpha)$ 的长度不超过原像 $\alpha$ 的长度, 可以画图，不管 $\text{Im }\sigma,\ker\sigma$ 的夹角是锐角还是钝角，总能找到 $\alpha$ 使得 $|\sigma(\alpha)|>|\alpha|$ ,这表明只能是 $\text{Im }\sigma\perp\ker\sigma$.

下面来看3个例题，其中例3是例2的推广，例2是例1的推广，3个例子中的构造均含有明显的几何意义: $\alpha$ 减去其在 $\mathrm{Im}\varphi_i$ 上的投影，剩余的部分是 $\mathrm{Ker}\varphi_i$ 上的分量，在例3中，可以看到这类问题不用在整体上考虑，只需考虑在 $\mathrm{Ker}\varphi_i$ 上的不断投影就足够了

> [!example] 例1
>设 $\varphi_1, \dots, \varphi_m$ 是 $n$ 维线性空间 $V$ 上的线性变换, 且适合条件: $\varphi_i^2 = \varphi_i, \varphi_i \varphi_j = 0 (i \ne j), \text{Ker} \, \varphi_1 \cap \dots \cap \text{Ker} \, \varphi_m = 0$. 求证: $V$ 是 $\text{Im} \, \varphi_1, \dots, \text{Im} \, \varphi_m$ 的直和.

证明: 任取 $\alpha \in \text{Im} \, \varphi_i \cap (\sum_{j \ne i} \text{Im} \, \varphi_j)$, 设 $\alpha = \varphi_i(\beta)$, 其中 $\beta \in V$, 则 $\varphi_i(\alpha) = \varphi_i^2(\beta) = \varphi_i(\beta) = \alpha$. 又可设
$$\alpha = \varphi_1(\alpha_1) + \dots + \varphi_{i-1}(\alpha_{i-1}) + \varphi_{i+1}(\alpha_{i+1}) + \dots + \varphi_m(\alpha_m),$$
于是
$$\alpha = \varphi_i(\alpha) = \varphi_i(\varphi_1(\alpha_1) + \dots + \varphi_{i-1}(\alpha_{i-1}) + \varphi_{i+1}(\alpha_{i+1}) + \dots + \varphi_m(\alpha_m)) = 0.$$
因此 $\text{Im} \, \varphi_i \cap (\sum_{j \ne i} \text{Im} \, \varphi_j) = 0$.
对 $V$ 中任一向量 $\alpha$ 以及任意的 $i$, 有
$$\varphi_i(\alpha - (\varphi_1(\alpha) + \dots + \varphi_m(\alpha))) = \varphi_i(\alpha) - \varphi_i^2(\alpha) = 0,$$
因此
$$\alpha - (\varphi_1(\alpha) + \dots + \varphi_m(\alpha)) \in \text{Ker} \, \varphi_1 \cap \dots \cap \text{Ker} \, \varphi_m = 0,$$
从而 $\alpha - (\varphi_1(\alpha) + \dots + \varphi_m(\alpha)) = 0$, 即 $\alpha = \varphi_1(\alpha) + \dots + \varphi_m(\alpha)$, 于是 $V = \text{Im} \, \varphi_1 + \dots + \text{Im} \, \varphi_m$. 这就证明了 $V$ 是 $\text{Im} \, \varphi_1, \dots, \text{Im} \, \varphi_m$ 的直和. 

> [!example] 例
>设 $\varphi_1, \dots, \varphi_k$ 是 $n$ 维线性空间 $V$ 上的线性变换, 满足条件 $\varphi_i^2 = \varphi_i(1 \le i \le k)$, $\varphi_i \varphi_j = 0 (i \ne j)$. 求证:
$$V = \text{Im} \, \varphi_1 \oplus \dots \oplus \text{Im} \, \varphi_k \oplus \left( \bigcap_{i=1}^k \text{Ker} \, \varphi_i \right).$$

令 $\varphi_{k+1} = I - (\varphi_1 + \dots + \varphi_k)$, 容易验证 $\varphi_i \varphi_{k+1} = \varphi_{k+1} \varphi_i = 0 (1 \le i \le k)$, $\varphi_{k+1}^2 = \varphi_{k+1}$, $\text{Ker} \, \varphi_1 \cap \dots \cap \text{Ker} \, \varphi_k \cap \text{Ker} \, \varphi_{k+1} = 0$ 以及 $\text{Im} \, \varphi_{k+1} = \bigcap_{i=1}^k \text{Ker} \, \varphi_i$, 于是由例 1 即得结论.

> [!example] 例
>设 $\varphi_1, \dots, \varphi_k$ 是 $n$ 维线性空间 $V$ 上的线性变换, 满足条件 $\varphi_i^2 = \varphi_i (1 \le i \le k)$, $\varphi_i \varphi_j = 0 (1 \le i < j \le k)$. 求证:
$$V = \text{Im} \, \varphi_1 \oplus \dots \oplus \text{Im} \, \varphi_k \oplus \left( \bigcap_{i=1}^k \text{Ker} \, \varphi_i \right).$$

**step1: 证明直和** 
根据直和的充要条件，只要证明零向量分块表示唯一即可. 设
$$0 = \varphi_1(\alpha_1) + \varphi_2(\alpha_2) + \dots + \varphi_k(\alpha_k) + \beta, $$
其中 $\alpha_1, \alpha_2, \dots, \alpha_k \in V, \beta \in \bigcap_{i=1}^k \text{Ker} \, \varphi_i$. 上式两边同时作用 $\varphi_1$, 注意到 $\varphi_1 \varphi_i = 0 (i > 1)$ 以及 $\varphi_1(\beta) = 0$, 故 $0 = \varphi_1^2(\alpha_1) = \varphi_1(\alpha_1)$, 于是上式右边可以去掉 $\varphi_1(\alpha_1)$.上式两边再同时作用 $\varphi_2$, 同理可得 $\varphi_2(\alpha_2) = 0$. 依次这样做下去, 最后可得
$$\varphi_1(\alpha_1) = \varphi_2(\alpha_2) = \dots = \varphi_k(\alpha_k) = \beta = 0.$$

**step2: 证明可分解性**
对任意的 $\alpha \in V$, 容易验证
$$
\begin{aligned}
\alpha &= \varphi_1(\alpha) + \varphi_2(I_V - \varphi_1)(\alpha) + \varphi_3(I_V - \varphi_2)(I_V - \varphi_1)(\alpha) \\\\ &+ \dots + \varphi_k(I_V - \varphi_{k-1}) \cdots (I_V - \varphi_1)(\alpha) + (I_V - \varphi_k)(I_V - \varphi_{k-1}) \cdots (I_V - \varphi_1)(\alpha),
\end{aligned}
$$
其中 
$$
\begin{aligned}
\varphi_1(\alpha) &\in \text{Im}  \varphi_1, \\ \varphi_2(I_V - \varphi_1)(\alpha) &\in \text{Im} \, \varphi_2,\\ \varphi_3(I_V - \varphi_2)(I_V - \varphi_1)(\alpha) &\in \text{Im} \, \varphi_3, \\ &\cdots \cdots, \\ \varphi_k(I_V - \varphi_{k-1}) \cdots (I_V - \varphi_1)(\alpha) &\in \text{Im} \, \varphi_k, \\ (I_V - \varphi_k)(I_V - \varphi_{k-1}) \cdots (I_V - \varphi_1)(\alpha) &\in \bigcap_{i=1}^k \text{Ker} \, \varphi_i
\end{aligned}
$$
于是就完成了证明

> step2 的分解思想是, 依次使用幂等变换 $\varphi_i$ 的投影分解，不断在核上进行迭代投影: $\alpha = \varphi_1(\alpha) + (I_V - \varphi_1)(\alpha)$, $(I_V - \varphi_1)(\alpha) = \varphi_2(I_V - \varphi_1)(\alpha) + (I_V - \varphi_2)(I_V - \varphi_1)(\alpha)$, $\dots$; 就能得到要求的分解式
