# 问题 2017A04

> [!question] 问题 2017A04
> 设 A, B, C 均为 2 阶方阵, 满足 C = AB - BA, AC = CA 和 BC = CB, 求证: C = O.

## 解答
由 C = AB - BA 以及 AC = CA 可得

$$
\boldsymbol {C} ^ {2} = \boldsymbol {C A B} - \boldsymbol {C B A} = \boldsymbol {A} (\boldsymbol {C B}) - (\boldsymbol {C B}) \boldsymbol {A},
$$

故由矩阵迹的性质可得 $\operatorname{tr}(\pmb {C}) = \operatorname{tr}(\pmb{C}^2) = 0$，设 $C = (c_{ij})$，则有 $\operatorname{tr}(\pmb {C}) = c_{11} + c_{22} = 0$ 以及 $\operatorname{tr}(\pmb{C}^2) = 2(c_{11}^2 +c_{12}c_{21}) = 0.$ 若 $c_{12} = c_{21} = 0,$ 则 $c_{11} = c_{22} = 0,$ 于是 $\pmb {C} = \pmb{O}$，结论得证. 若 $c_{12},c_{21}$ 不全为零，则由矩阵的转置不妨假设 $c_{21}\neq 0.$ 令 $\pmb {P} = \left(\begin{array}{cc}c_{11} & 1\\ c_{21} & 0 \end{array} \right),$ 则 $|\pmb {P}| = -c_{21}\neq 0,$ 即 $\pmb{P}$ 为可逆阵. 经计算可知

$$
\boldsymbol {C P} = \left( \begin{array}{c c} c _ {1 1} & c _ {1 2} \\ c _ {2 1} & - c _ {1 1} \end{array} \right) \left( \begin{array}{c c} c _ {1 1} & 1 \\ c _ {2 1} & 0 \end{array} \right) = \left( \begin{array}{c c} 0 & c _ {1 1} \\ 0 & c _ {2 1} \end{array} \right) = \left( \begin{array}{c c} c _ {1 1} & 1 \\ c _ {2 1} & 0 \end{array} \right) \left( \begin{array}{c c} 0 & 1 \\ 0 & 0 \end{array} \right) = \boldsymbol {P N},
$$

其中 $N = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$ 是二阶幂零 Jordan 块 (参考[[例 2.2]])，即有 $P^{-1}CP = N$。将条件改写为 $(P^{-1}AP)(P^{-1}CP) = (P^{-1}CP)(P^{-1}AP)$， $(P^{-1}BP)(P^{-1}CP) = (P^{-1}CP)(P^{-1}BP)$，经过计算可得 $P^{-1}AP = \begin{pmatrix} 0 & a \\ 0 & 0 \end{pmatrix} = aN$， $P^{-1}BP = \begin{pmatrix} 0 & b \\ 0 & 0 \end{pmatrix} = bN$，于是

$$
\boldsymbol {P} ^ {- 1} \boldsymbol {C P} = (\boldsymbol {P} ^ {- 1} \boldsymbol {A P}) (\boldsymbol {P} ^ {- 1} \boldsymbol {B P}) - (\boldsymbol {P} ^ {- 1} \boldsymbol {B P}) (\boldsymbol {P} ^ {- 1} \boldsymbol {A P}) = (a \boldsymbol {N}) (b \boldsymbol {N}) - (b \boldsymbol {N}) (a \boldsymbol {N}) = \boldsymbol {O},
$$

即 C = O, 这与 $c_{21} \neq 0$ 矛盾.
